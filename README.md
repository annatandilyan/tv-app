# TV Streaming Application

## Project Overview

A modern TV streaming application built with React and TypeScript.

## Features
- Movie app UI based on the design provided
- Home page of movies
- Animated Sidebar
- Trending movies carousel
- The TV app is fully accessible by keyboard (tabs) as its going to be used by the controller

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui (headless UI components with theme and accessibility)
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd tv-app-lovable

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

## Development

The application will be available at `http://localhost:8080` after running `npm run dev`.

## Build

To build the application for production:

```sh
npm run build
```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run build:dev` - Build for development
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build
